# Sprinter

Sprinter is a social training app for sprinters. Athletes and squads log sprint sessions, track personal bests and progress, and compete in challenges and leaderboards.

My Final Year Project for CT413, built for brief FG2, "GroupXercisE: A Social Fitness and Motivation Platform".

## Stack

- Expo (React Native) with Expo Router
- TypeScript
- Supabase (Postgres, Auth, Realtime)
